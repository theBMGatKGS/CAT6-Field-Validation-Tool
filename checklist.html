Project Information
⚠ CAT 5 (non-e) Notice: CAT 5 is not a recognized category in ANSI/TIA-568.2-D — it was removed in the TIA-568-C revision. Formal TIA-568 certification is not available for CAT 5. It is designed for 100BASE-TX (100 Mbps); 1000BASE-T (Gigabit) is not guaranteed. Link speed pass threshold for this checklist is set to 100 Mbps for CAT 5 rows. Use CAT 5e or higher for any new construction requiring a certifiable standard.
